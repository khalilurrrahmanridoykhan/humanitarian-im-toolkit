# Humanitarian IM & Rapid Mapping Toolkit

Project-based portfolio proving the **Kobo/ODK + Esri Field Maps + rapid mapping**
skill set used in humanitarian & disaster-response information management —
built for roles like IOM NPM (Needs & Population Monitoring), UNHCR Information
Management Officer, REACH Assessment/GIS Officer, BRAC HCMP, DDM, and CARE.

Builds on production field-data/GIS work already shipped elsewhere in this
portfolio (ODK/KoBoToolbox at GMGI, the BRAC Microstratification System —
11,448 GPS-referenced villages — and
[`geohealth-risk-mapping`](https://github.com/khalilurrrahmanridoykhan/geohealth-risk-mapping)
for the remote-sensing side), and closes the specific tool gaps real job ads in
this sector ask for that weren't covered yet.

**Synthetic / public data only** — no real beneficiary, camp-resident, or
displaced-population data is used anywhere in this repo.
